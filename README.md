# 投資リスク許容度診断クイズ

10問の質問（投資スタイル・資産状況・感情反応）で投資家タイプを判定し、推奨ポートフォリオ配分を表示するツール。

## 機能

- 10問×5択の診断クイズ（ステップ表示・前後移動可）
- スコア集計 → 超保守 / 保守 / バランス / 積極 / 超積極の5タイプ判定
- タイプ別の推奨資産配分（株式/債券/現金/コモディティ）をSVG円グラフで表示
- タイプの特徴・注意点・推奨商品カテゴリの解説
- 投資診断免責注意書き付き
- localStorageで結果保存・次回起動時自動復元

## 技術仕様

- バニラJS / Tailwind CDN / インラインSVG
- XSSガード実装済み（escHtml関数）
- レスポンシブ対応
- 全インタラクティブ要素にaria-label付与
